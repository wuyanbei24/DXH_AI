## 2. 报文帧结构设计

### 2.1 通用帧格式 (所有报文)

考虑FT232 1KB缓存限制，设计帧结构如下：

```
┌──────────┬────────────┬──────────────┬──────────────┬──────────────┬──────────┬──────────┐
│  SYNC    │ PacketType │ PacketIndex  │ PacketLength │   Payload    │  CRC16   │   END    │
│ (2字节)  │  (1字节)   │   (2字节)    │   (2字节)    │  (N字节)     │ (2字节)  │ (1字节)  │
└──────────┴────────────┴──────────────┴──────────────┴──────────────┴──────────┴──────────┘
```

### 2.2 字段定义

| 字段 | 偏移 | 长度 | 描述 |
|------|------|------|------|
| SYNC | 0 | 2 | 同步字 0x55AA (上行) / 0xAA55 (下行) |
| PacketType | 2 | 1 | 报文类型标识 |
| PacketIndex | 3 | 2 | 报文序号 (0-65535循环) |
| PacketLength | 5 | 2 | Payload长度 (0-1012字节) |
| Payload | 7 | N | 有效数据 (最大1012字节) |
| CRC16 | 7+N | 2 | CRC16校验 (CCITT标准) |
| END | 9+N | 1 | 帧结束标志 0x0D |

**帧长度**: 10 + N 字节 (N ≤ 1012，保证单帧≤1022字节 < 1KB)

### 2.3 PacketType 定义

#### 下行报文 (x86 → FPGA)
| 类型码 | 名称 | 描述 |
|--------|------|------|
| 0x01 | CMD_REG_WRITE | 寄存器写入命令 |
| 0x02 | CMD_REG_READ | 寄存器读取请求 |
| 0x03 | CMD_WAVE_CONFIG | 波形配置数据 |
| 0x04 | CMD_WAVE_BATCH | 批量波形数据 |
| 0x05 | CMD_SYS_CTRL | 系统控制命令 |
| 0x06 | CMD_STATUS_REQ | 状态查询请求 |
| 0x0F | CMD_ACK | 应答确认 |

#### 上行报文 (FPGA → x86)
| 类型码 | 名称 | 描述 |
|--------|------|------|
| 0x81 | RSP_REG_DATA | 寄存器读取响应 |
| 0x82 | RSP_STATUS | 状态信息上报 |
| 0x83 | RSP_ADC_DATA | ADC采样数据 |
| 0x84 | RSP_ADC_BATCH | 批量ADC数据 |
| 0x85 | RSP_ERROR | 错误信息上报 |
| 0x8F | RSP_ACK | 应答确认 |

## 3. Payload 详细设计

### 3.1 寄存器操作

#### CMD_REG_WRITE (0x01) - 寄存器写入
```
Payload结构:
┌──────────────┬──────────────┬──────────────┐
│  RegAddr     │   RegData    │   Reserved   │
│  (4字节)     │   (4字节)    │   (4字节)    │
└──────────────┴──────────────┴──────────────┘
总长度: 12字节
```

#### CMD_REG_READ (0x02) - 寄存器读取
```
Payload结构:
┌──────────────┬──────────────┐
│  RegAddr     │   Count      │
│  (4字节)     │   (2字节)    │
└──────────────┴──────────────┘
总长度: 6字节
```

#### RSP_REG_DATA (0x81) - 寄存器数据响应
```
Payload结构:
┌──────────────┬──────────────┬──────────────────────────────┐
│  RegAddr     │   Count      │   RegData[0..N-1]            │
│  (4字节)     │   (2字节)    │   (N×4字节)                  │
└──────────────┴──────────────┴──────────────────────────────┘
```

### 3.2 波形配置

#### CMD_WAVE_CONFIG (0x03) - 单条波形配置
```
Payload结构:
┌──────────────┬──────────────┬──────────────────────────────────────────┐
│  WaveIndex   │  WaveLength  │   WaveData[0..N-1]                       │
│  (2字节)     │   (1字节)    │   (N×4字节, N=4~8)                       │
└──────────────┴──────────────┴──────────────────────────────────────────┘
有效范围: WaveIndex: 0-9999, WaveLength: 4-8
总长度: 3 + N×4 字节 (19-35字节)
```

#### CMD_WAVE_BATCH (0x04) - 批量波形配置
```
Payload结构:
┌──────────────┬──────────────┬─────────────────────────────────────────────┐
│  StartIndex  │  WaveCount   │   WaveEntry[0..M-1]                         │
│  (2字节)     │   (2字节)    │   (M × WaveEntrySize)                       │
└──────────────┴──────────────┴─────────────────────────────────────────────┘

WaveEntry结构 (固定长度模式):
┌──────────────┬──────────────────────────────────────┐
│  WaveLength  │   WaveData[0..7]                     │
│  (1字节)     │   (8×4=32字节, 不足补0)              │
└──────────────┴──────────────────────────────────────┘
单个WaveEntry: 33字节

最大批量数: (1012-4) / 33 = 30条/帧
```

### 3.3 ADC数据上传

**设计说明**: ADC数据上行采用**定长512字节Payload**，简化FPGA实现和上位机解析。

#### RSP_ADC_DATA (0x83) - ADC采样数据 (定长512字节)
```
Payload结构 (固定512字节):
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────────────────────┬──────────────┐
│  Timestamp   │  ChannelMask │  SampleCount │  Reserved    │   SampleData[0..123]         │  Padding     │
│  (4字节)     │   (2字节)    │   (2字节)    │   (4字节)    │   (124×4=496字节)            │  (4字节)     │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────────────────────┴──────────────┘

字段说明:
- Timestamp:   32位时间戳 (系统时钟计数)
- ChannelMask: 通道使能掩码
- SampleCount: 有效采样点数 (≤124)
- Reserved:    保留字段，填充0x00
- SampleData:  固定124个32位采样点空间，不足部分填0
- Padding:     尾部填充，确保512字节对齐

固定采样点数: 124个32位采样点/帧
帧总长度: 10(开销) + 512(Payload) = 522字节
```

#### RSP_ADC_BATCH (0x84) - 分片ADC数据 (定长512字节)
```
用于大量ADC数据的分片传输，每片固定512字节Payload

Payload结构 (固定512字节):
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────────────────────┬──────────────┐
│  TotalFrames │  FrameSeq    │  Timestamp   │  SampleCount │   SampleData[0..123]         │  Padding     │
│  (2字节)     │   (2字节)    │   (4字节)    │   (2字节)    │   (124×4=496字节)            │  (6字节)     │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────────────────────┴──────────────┘

字段说明:
- TotalFrames: 总帧数
- FrameSeq:    当前帧序号 (0起始)
- Timestamp:   首帧时间戳
- SampleCount: 本帧有效采样点数 (≤124)
- SampleData:  固定124个32位采样点空间
- Padding:     尾部填充至512字节
```

### 3.4 状态与控制

#### RSP_STATUS (0x82) - 状态信息
```
Payload结构:
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│ SysStatus    │ DDRStatus    │ WaveCount    │ ADCStatus    │ ErrorCode    │ Reserved     │
│ (4字节)      │ (4字节)      │ (2字节)      │ (4字节)      │ (2字节)      │ (4字节)      │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
总长度: 20字节

SysStatus位定义:
  Bit[0]: 系统就绪
  Bit[1]: DDR初始化完成
  Bit[2]: ADC就绪
  Bit[3]: 发射使能
  Bit[7:4]: 运行模式
  Bit[15:8]: 固件版本
  Bit[31:16]: 预留
```

#### CMD_SYS_CTRL (0x05) - 系统控制
```
Payload结构:
┌──────────────┬──────────────┬──────────────┐
│  CtrlCmd     │  CtrlParam   │  Reserved    │
│  (2字节)     │   (4字节)    │   (4字节)    │
└──────────────┴──────────────┴──────────────┘

CtrlCmd定义:
  0x0001: 系统复位
  0x0002: 启动发射
  0x0003: 停止发射
  0x0004: DDR清空
  0x0005: ADC启动采集
  0x0006: ADC停止采集
```

### 4.4 应答机制

每个命令帧应有对应的应答帧:

```
RSP_ACK (0x8F) Payload结构:
┌──────────────┬──────────────┬──────────────┐
│  AckType     │  AckIndex    │  AckResult   │
│  (1字节)     │   (2字节)    │   (1字节)    │
└──────────────┴──────────────┴──────────────┘

AckResult:
  0x00: 成功
  0x01: CRC错误
  0x02: 长度错误
  0x03: 类型不支持
  0x04: 参数错误
  0x05: 执行失败
  0x06: 忙
```

## 5. 流控设计

### 5.1 FT232 Sync FIFO 流控信号

| 信号 | 方向 | 说明 |
|------|------|------|
| TXE# | FT232→FPGA | TX缓冲空(可写) |
| RXF# | FT232→FPGA | RX缓冲有数据(可读) |
| WR# | FPGA→FT232 | 写使能 |
| RD# | FPGA→FT232 | 读使能 |

### 5.2 软件流控机制

```c
// x86端发送逻辑伪代码
int send_packet(packet_t *pkt) {
    int retry = 0;
    while (retry < MAX_RETRY) {
        // 发送数据包
        ft232_write(pkt->data, pkt->length);
        
        // 等待ACK (超时500ms)
        if (wait_ack(pkt->index, 500) == ACK_SUCCESS) {
            return SUCCESS;
        }
        retry++;
    }
    return TIMEOUT;
}
```

### 5.3 批量传输优化

考虑10000条波形配置的高效传输:

```
每帧最大30条波形 (33字节×30 = 990字节 < 1012字节限制)
总帧数 = ceil(10000 / 30) = 334帧
单帧传输时间 ≈ 1KB / 480Mbps × 8 ≈ 17μs (USB传输)
加上处理延迟，预估 500μs/帧
总传输时间 ≈ 334 × 500μs ≈ 167ms
```

## 6. CRC校验

### 6.1 CRC16-CCITT 算法

```c
// 多项式: 0x1021
// 初始值: 0xFFFF
uint16_t crc16_ccitt(uint8_t *data, uint16_t length) {
    uint16_t crc = 0xFFFF;
    for (uint16_t i = 0; i < length; i++) {
        crc ^= (uint16_t)data[i] << 8;
        for (uint8_t j = 0; j < 8; j++) {
            if (crc & 0x8000)
                crc = (crc << 1) ^ 0x1021;
            else
                crc <<= 1;
        }
    }
    return crc;
}
```

### 6.2 校验范围
CRC计算范围: SYNC到Payload末尾 (不含CRC和END字段)
